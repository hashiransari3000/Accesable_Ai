ACCESSABLE AI - SETUP GUIDE (Linux)
===================================

1. PREREQUISITES
----------------
  - Python 3.10 or newer (developed and tested with Python 3.14)
  - Git
  - espeak-ng for offline speech:
      sudo dnf install espeak-ng        # Fedora
      sudo apt install espeak-ng        # Debian/Ubuntu
    Verify with: espeak-ng --version

2. GET THE CODE
---------------
      git clone https://github.com/hashiransari3000/Accesable_Ai.git
      cd Accesable_Ai

3. CREATE A VIRTUAL ENVIRONMENT
-------------------------------
      python3 -m venv .venv
      source .venv/bin/activate

4. INSTALL PYTHON PACKAGES
--------------------------
  Install the CPU-only build of torch first to avoid multi-gigabyte CUDA
  downloads:

      pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
      pip install -r requirements.txt

  Main packages (pinned in requirements.txt):
      streamlit        UI framework
      ultralytics      YOLO11n detection and YOLO-World
      opencv-python    image handling and annotation
      pillow           image utilities
      transformers     optional relative-depth model
      matplotlib       route-map rendering
      pyttsx3          offline text-to-speech wrapper
      easyocr          local OCR (loaded on demand)
      pytest           test runner

  Only espeak-ng is a system package; everything else installs with pip.

5. MODEL DOWNLOADS
------------------
  Models download automatically on first use and are cached locally. After
  that, the app works offline.

      YOLO11n                  ~5.4 MB    models/yolo11n.pt
      YOLO-World v2            ~24.7 MB   models/yolov8s-worldv2.pt
        + CLIP text encoder    ~354 MB    weights/clip/ (first open-vocab run)
      Depth Anything V2 Small  ~100 MB    ~/.cache/huggingface/
      EasyOCR English          ~95 MB     ~/.EasyOCR/

  No paid services, accounts, or API keys are involved.

6. RUN THE APP
--------------
      streamlit run app.py

  Open http://localhost:8501.

  To serve the demo on a network interface:
      streamlit run app.py --server.port 8501 --server.address 0.0.0.0

  A public deployment has no built-in login. Do not upload sensitive images
  to a shared or public instance.

7. RUN THE TESTS
----------------
      pytest -q

8. TROUBLESHOOTING
------------------
  T1  No speech
      -> Install espeak-ng. Speech degrades to text-only output; the app
         remains usable.

  T2  First detection is slow
      -> Model weights are downloading on first use; later runs are fast.

  T3  Camera not detected or permission denied
      -> Image upload still works. Check OS camera permissions. On Linux the
         user may need to be in the 'video' group:
         sudo usermod -aG video $USER

  T4  Memory pressure
      -> OCR, depth, and open-vocabulary models load only when requested.
         Close other heavy applications.

  T5  Package install fails
      -> Use a supported Python version (3.11-3.14) and keep the pinned
         versions. If a wheel is missing, try Python 3.12:
         python3.12 -m venv .venv

  T6  "operator torchvision::nms does not exist"
      -> torch/torchvision mismatch. Reinstall both CPU builds together:
         pip install --upgrade torch torchvision \
             --index-url https://download.pytorch.org/whl/cpu

  T7  Port 8501 busy
      -> streamlit run app.py --server.port 8502

9. PRIVACY NOTE
---------------
  The app does not save uploaded images, OCR text, or voice data, and it
  contains no analytics. When you run it locally, processing stays on your
  machine. On a hosted instance, images are processed in memory on the hosting
  server; avoid uploading sensitive content to a public deployment. The only
  network use is the one-time model download.
